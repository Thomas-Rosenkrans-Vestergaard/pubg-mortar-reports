# PUBG mortar moments

Timestamps from PUBG esports broadcasts where a mortar shows up — either the casters
talking about one, or one actually landing in the killfeed.

**Published site: https://thomas-rosenkrans-vestergaard.github.io/pubg-mortar-reports/**

Every timestamp link starts 30 seconds before the moment itself, so the video opens with
enough run-up to see the context.

Each entry is tagged with where it came from:

- `casters` — the commentary mentions a mortar (or C4), read from the broadcast captions.
- `killfeed` — a mortar icon was detected in the broadcast kill feed, meaning a mortar
  actually hit someone.

Caption text comes from YouTube's automatic captions, so it is not perfect — that is why
every entry quotes the surrounding words. Skim the quote before forwarding.

## Contents

- `index.html` — the landing page, listing every broadcast
- `<video_id>.html` — one page per broadcast
- `<video_id>.md` — the same report in Markdown, which is what the site is built from

## Updating

Generated by [pubg-mortar-detection](https://github.com/Thomas-Rosenkrans-Vestergaard/pubg-mortar-detection):

```bash
python mortar_scan.py --killfeed <video-id>   # writes reports/<id>.md
python build_site.py                          # rebuilds the HTML in place
```

Then commit and push from this directory. GitHub Pages serves the branch directly, so the
site updates on push with no build step.
